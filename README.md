# STUDENT-MANAGEMENT-SYSTEM-PYTHON-PROJECT
The Student Management System is a simple yet efficient Python program that helps manage basic student information such as name, roll number, and marks.
It allows users to add, view, search, update, and delete student records.
All data is securely saved in a text file, ensuring that records remain available even after the program is closed.

 Features :

➕ Add New Student: Enter and store new student details easily.

📋 View All Students: Display all records in a clean and readable format.

🔍 Search Student: Quickly find a student using their roll number.

✏️ Update Marks: Modify marks of any student without affecting other records.

❌ Delete Student: Remove a specific student’s record from the system.

💾 Data Persistence: All data is stored in students.txt for future use.

How It Works :

When the program starts, it loads existing records from the students.txt file.

A simple menu appears with six options (Add, View, Search, Update, Delete, Exit).

Based on your selection, the respective function is executed.

Any changes you make are automatically saved back to the file.

Technologies Used :

Language: Python 3.x

Concepts: File Handling, Lists, Dictionaries, Functions, Loops, Exception Handling

Storage: Text file (students.txt)
